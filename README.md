# Task Manager

## Overview
Task Manager is a simple React application that allows users to create, manage, and delete tasks with different priority levels.

## Features
- Add new tasks with a title and priority (low, medium, high).
- Mark tasks as completed or incompleted.
- Delete tasks from the list.
- Priorities are visually represented with different colors.

## Installation
```sh
# Clone the repository
git clone https://github.com/yourusername/task-manager.git

# Navigate to the project directory
cd task-manager

# Install dependencies
npm install

```

# Start the development server
npm start

The application will open at http://localhost:3000/.
